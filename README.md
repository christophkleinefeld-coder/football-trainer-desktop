# Fußballtrainer Desktop App

Diese App ist ein MVP für eine Windows-Desktop-Anwendung für Fußballtrainer mit Funktionen für:

- Trainingsplanung
- Mannschaftsmanagement
- Spieler und Anwesenheiten
- Übungsbibliothek
- Kalender und Termine
- Dashboard

## Stack

- .NET 8
- WPF (Windows Desktop)
- SQLite

## Voraussetzungen

- Windows 10/11
- .NET 8 SDK
- Visual Studio 2022 oder VS Code mit C# Erweiterung

## Starten

```bash
dotnet restore
 dotnet build
 dotnet run --project FootballTrainer/FootballTrainer.csproj
```

## Projektstatus

Dies ist eine funktionale Basis-Version mit zentralen Datenmodellen und einer nutzbaren Oberfläche. Die Videoanalyse, KI-Tracking und taktische Präsentation sind für spätere Iterationen vorgesehen.
